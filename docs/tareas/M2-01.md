# M2-01 · Proyecto Unity 6 e integración de Sim.Core

- **Estado:** ✅ hecho
- **Modelo · esfuerzo:** Sonnet · medium
- **Dónde:** 🖥️ PC
- **Depende de:** M0-05, M1-12

## Objetivo
Crear el proyecto de Unity 6 LTS (URP móvil, Input System, UI Toolkit, Burst, Collections, Addressables), estructura de carpetas (GDD §19.3) e integración de `Sim.Core` como paquete local o DLL

## Archivos
unity/URBE/ (Assets/, Packages/, ProjectSettings/), unity/URBE/Assets/Tests/PlayMode/

## Contexto del GDD
§19.3 Estructura, §8.14 Determinismo

## Aceptación / verificación
El proyecto abre sin errores; un test de PlayMode crea un `SimState`

## Notas de traspaso
- **Unity usado:** 6000.1.4f1 (Unity 6.1, rama de actualización, **no LTS**; era el único Unity 6 instalado). La tarjeta pedía LTS: conviene migrar a la LTS de Unity 6 cuando se instale (cambiar `ProjectSettings/ProjectVersion.txt` y reabrir).
- **Paquetes** (`Packages/manifest.json`): URP 17.1.0, Input System 1.14.0 (solo el nuevo: `activeInputHandler: 1`), UI Toolkit (módulo integrado), Burst 1.8.19, Collections 2.5.1, Addressables 2.3.1, Mathematics, Test Framework 1.5.1.
- **Estructura** (GDD §19.3): `Assets/_Project/{Scripts,Art,UI,Audio,Data,Scenes,Settings}`; ensamblados `Game.Unity` (Scripts/), `Game.Editor` (Scripts/Editor/), `Game.Tests.EditMode` y `Game.Tests.PlayMode` (Assets/Tests/). `Game.Burst` queda para cuando haya un núcleo caliente que portar. La tarjeta nombraba `Assets/Scripts/...`; se usa `Assets/_Project/Scripts/...` por el GDD.
- **Sim.Core como DLL:** `tools/scripts/sync-simcore.ps1` (o `.sh`) hace `dotnet build -c Release sim/Sim.Core` y copia `Urbe.Sim.Core.dll` a `unity/URBE/Assets/Plugins/SimCore/`. La DLL está commiteada. Si cambia `sim/`, volver a ejecutar el script y commitear la DLL. Los asmdef de tests necesitan `Urbe.Sim.Core.dll` en `precompiledReferences` (ya puesto).
- **No existe `SimState`:** la raíz es `TrafficSimulation` + `RoadNetwork`. El test de PlayMode (`SimCoreIntegrationTests`) usa el porte de `Scenarios.Grid` (`Assets/_Project/Scripts/Sim/GridScenario.cs`, sin referenciar Sim.Runner), avanza 100 ticks y comprueba determinismo por `ComputeHash()` entre dos ejecuciones.
- **Configuración reproducible:** menú `URBE > Configurar proyecto` o `-executeMethod Urbe.Game.Editor.ProjectSetup.Apply` (crea `URP-Mobile` y `URP-PC`, asigna calidad, Linear, Android IL2CPP/ARM64/API 26, orientación automática).
- **Verificado:** importación en batchmode sin errores de compilación; PlayMode en batchmode 2/2 en verde. **No verificado:** build de Android (es M2-10) ni ejecución en móvil.
- Aviso inofensivo en el log: "assemblies without scripts" mientras `Game.Tests.EditMode` no tenía tests.
